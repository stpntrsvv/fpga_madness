# План работ

## Приоритет с 2026-10-20

По указанию пользователя программируемый GRD2 отложен. Ближайшая задача — производительность фиксированного GRD1: исследовать частотные ограничения и источник FCLK от PS; при недостаточном результате оценить увеличение числа трактов и банков. Сначала аппаратно подтверждённое сравнение с обычным C/NEON, затем возвращение к гибкости графа. Результаты исследования: [документ 24](24%20Ограничения%20частоты%20фиксированной%20сетки.md).
