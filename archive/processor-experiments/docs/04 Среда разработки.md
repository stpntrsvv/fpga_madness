# Среда разработки

macOS на Apple Silicon — основная среда редактирования, моделирования, сборки PL и работы с JTAG. Открытая цепочка Yosys, nextpnr-xilinx и Project X-Ray установлена через Apio и собирает прошивку XC7Z020 непосредственно на Mac.

```sh
cp .env.example .env
make doctor
```

Основные команды `make lint`, `make sim`, `make synth` и `make bitstream` используют открытые средства. Apio вызывается через `.venv/bin/python -m apio`, чтобы перенос каталога не ломал запускатель со старым абсолютным путём. `make sim` использует `scripts/sim.sh`, генерирует проверки моделей и запускает Icarus Verilog либо Verilator из OSS CAD Suite.

Vivado остаётся дополнительным средством для PS7, AXI, фирменных блоков и контрольных сборок; при `VIVADO_HOST` он вызывается через SSH. Временная конфигурация PL загружается локально через DAPLink и openFPGALoader. OpenOCD выполняет обнаружение цепочки и обмен с уже настроенным ядром через USER1 JTAG. Текущий порядок описан в [документе второго ядра](14%20Второе%20ядро.md); первый опыт сохранён отдельно.

Для текущего профиля использовать `make bitstream`: он проверяет временные ограничения и маршруты всех используемых входов данных DSP, исправляет известную ошибку управляющих битов DSP и создаёт `build/fpga_madness.bit` со свидетельством `.meta.json`. Маршруты сохраняются в `_build/default/hardware.routed.json`; пропуск любого используемого входа отклоняет сборку. Прямой результат Apio `_build/default/hardware.bit` не прошёл эти проверки и обработку DSP. `make program` проверяет контрольную сумму, свидетельство и предохранитель `ALLOW_FPGA_PROGRAM=YES`.

Без платы доступны `make lint`, `make sim`, `make bitstream`, `make sim-синтез` и `make сравнить`. Последняя команда измеряет только CPU, если нет ранее измеренной частоты для той же прошивки; отчёт второго ядра сохраняется отдельно в `reports/сравнение-автономное-ядро.json`.
