# Цель и границы

Цель проекта — исследовать процессор динамических систем: фиксированное железо с загружаемым описанием состояний, их связей и производных, которое самостоятельно выполняет много шагов эволюции.

Модель меняется без повторного синтеза FPGA. Состояния остаются внутри ядра между шагами. Основа исполнения — настроенный граф и согласованные переходы состояний; центральная выборка арифметических команд не является предлагаемым механизмом вычисления.

Первый инфраструктурный этап создал воспроизводимый путь от RTL до прошивки без зависимости от сохранённого проекта Vivado. В репозитории есть сборка, проверка RTL, моделирование, загрузка временной конфигурации PL и документация платы. Добавлен [первый профиль вычислительного ядра](11%20Первое%20ядро.md); его параметры выбраны для проверки гипотезы.

Текущий этап — реализация и проверка загружаемых графов на одном ядре, затем аппаратные испытания через DAPLink. См. [предложение архитектуры](09%20Архитектура%20машины%20состояний.md) и [план проверки гипотезы](10%20Проверка%20архитектурной%20гипотезы.md).

Первый функциональный результат получен: четыре разных графа прошли аппаратную проверку на одной конфигурации FPGA. Далее исследуем независимое тактирование, численный метод, цену коммутации и производительность. Работающий профиль пока использует обычную логику вместо DSP из-за аппаратного расхождения арифметики.

Пока не утверждены система команд, число интеграторов, топология сети, численное представление и метод интегрирования. Отдельно предстоит измерить цену программируемости относительно схемы под конкретную модель и скорость относительно оптимизированного CPU.

Текущий этап не включает QSPI/eFUSE, изменение SD-карты, Linux, DDR и приложения Cortex-A9. Подключение хоста и работа в реальном времени с внешними физическими устройствами рассматриваются позднее.
