# Устройство проекта

- `rtl/` — синтезируемый SystemVerilog.
- `tb/` — тестовые окружения.
- `constraints/` — проверенные XDC.
- `scripts/` — Vivado Tcl, JTAG и интеграция.
- `build/`, `reports/` — игнорируемые результаты.
- `docs/` — архитектура, решения и журнал.

`Makefile` — стабильный пользовательский API. PlatformIO и VS Code делегируют ему команды.
