# Завершённые процессорные опыты

Архив закрыт для дальнейшей разработки с 2026-10-27 по указанию пользователя.
Изменять его или возвращать в новую задачу только по отдельному запросу.
Слияние ветки `archive/processor-experiments` в `main` не выполняется.

Здесь сохранён целиком прежний проект: малые процессорные ядра, фиксированные
и программируемые сетки, сравнения с M1 и STM32N6, аппаратная документация
и сценарии. Исторический [README.md](README.md) описывает состояние опытов
до закрытия; его планы не являются текущими задачами.

Для воспроизведения открывать этот каталог как отдельный проект и запускать
команды из него. Относительные пути внутри проекта сохранены:

```sh
cd archive/processor-experiments
make doctor
make lint
make sim
```

Нужны Python со средой `.venv`, Apio и пакеты OSS CAD Suite и openXC7.
На текущем компьютере `.venv` — местная ссылка на среду в корне репозитория;
она не хранится в Git. После нового клонирования среду нужно подготовить
отдельно, руководствуясь историческим документом
[«Среда разработки»](docs/04%20Среда%20разработки.md).

Результаты `build/`, `_build/`, `reports/`, `.pio/` сохранены локально,
но исключены из Git. Старые образы после переноса не считать актуальными
без повторной проверки. Правила безопасности и предохранитель
`ALLOW_FPGA_PROGRAM=YES` сохранены; архивирование не разрешает запись на плату.
