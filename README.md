# FPGA Madness

Рабочее пространство для новой задачи на FPGA. Целевой кристалл — `xc7z020clg400-1`.

Предыдущие процессорные опыты завершены и обособлены в
[архиве](archive/processor-experiments/АРХИВ.md). Они сохранены в ветке
`archive/processor-experiments`; слияние в `main` не выполняется.

В корне пока нет нового RTL и сборки по умолчанию. Проверка доступности среды:

```sh
make doctor
```

Правила работы: [AGENTS.md](AGENTS.md). Сведения о плате:
[аппаратная часть](docs/03%20Аппаратная%20часть.md).
Решение об обособлении: [журнал решений](docs/05%20Журнал%20решений.md).
